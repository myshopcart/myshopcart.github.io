THE FIND EDIT — SHOPEE AFFILIATE WEBSITE STARTER
=================================================

WHAT'S INCLUDED
- index.html: website structure and page text
- styles.css: responsive black-and-white styling
- products.js: product list you can edit
- script.js: search and category filters

IMPORTANT
This is a starter website with sample products and placeholder Shopee URLs. Replace every sample item with real products and your own approved Shopee affiliate links before publishing. The default links go to Shopee's homepage, not to your affiliate account.

HOW TO EDIT YOUR PRODUCTS
1. Open products.js in Notepad, VS Code, or another text editor.
2. Find the products array.
3. For each product, edit:
   - name: product name
   - category: Beauty, Fashion, Lifestyle, or Tech (or add your own category)
   - description: short honest description
   - price: optional; check it before publishing because prices change
   - image: direct image URL or a local image path such as "images/bag.jpg"
   - url: paste your actual Shopee affiliate link
   - tag: small label on the product image
4. Save the file. Keep products.js in the same folder as index.html.
5. Open index.html in your browser to preview the site.

ADDING PRODUCT IMAGES
Option A: Use a direct image URL in the image field.
Option B: Create an "images" folder next to index.html, place your image files inside it, and set image to e.g. "images/product-name.jpg".
Use images you have permission to use and follow Shopee's affiliate/program rules for product images and promotion.

ADDING MORE PRODUCTS
Copy one product object (the text between { and }) inside the products array, paste it after the last product, and separate objects with commas. Ensure each object has a comma between it and the next object.

PUBLISHING FOR FREE WITH GITHUB PAGES
1. Sign in or create an account at https://github.com/
2. Create a new public repository, e.g. "the-find-edit".
3. Upload index.html, styles.css, products.js, and script.js to the repository's top level. Upload the images folder too if you used local images.
4. Open the repository's Settings.
5. Select Pages from the left menu.
6. Under Build and deployment, choose "Deploy from a branch".
7. Choose the main branch and the /(root) folder, then save.
8. Wait for GitHub Pages to publish the site. The Pages screen will show your live URL.
9. Open the URL on your phone and computer to test the search, categories, product images, and affiliate links.

ALTERNATIVE HOSTING
You can also publish this static website using Netlify or Cloudflare Pages. Follow their current instructions for deploying a static HTML/CSS/JS site.

BEFORE SHARING
- Replace all sample products and default URLs with your real affiliate links.
- Click every product link and confirm it opens the correct product page.
- Check product photos, spelling, and any prices.
- Keep the affiliate disclosure visible and accurate.
- Confirm your affiliate program permits the website, your traffic sources, and the way you use links/images.
- Do not imply that your site is owned by or officially affiliated with Shopee.
- Use your own website name after checking that it is not already used by another brand.
